# Quiz Web

Mini-projet Web FIA3 - ISSAT Sousse - A.U. 2025/2026
Sujet 7 : Page de quiz interactif

## Description

Quiz sur HTML, CSS et JavaScript avec :

- un chronomètre de 15 secondes par question ;
- un score avec pénalités de temps (10 points, -1 point toutes les 3 secondes) ;
- un feedback immédiat après chaque réponse ;
- les 5 meilleurs scores sauvegardés avec localStorage ;
- des questions QCM et Vrai/Faux, une barre de progression, une animation entre les questions et un bouton « Rejouer ».

## Fichiers

- `index.html` : structure de la page (accueil, quiz, résultat)
- `style.css` : mise en forme et responsive
- `script.js` : logique du quiz (classe `Quiz`)

## Lancer le projet

Ouvrir `index.html` dans un navigateur, ou utiliser l'extension Live Server de VS Code.
